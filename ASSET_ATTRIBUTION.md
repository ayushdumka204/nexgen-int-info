# Homepage imagery

The interface uses self-hosted Inter from the public Google Fonts catalog.
Its Latin WOFF2 subset is stored in `public/assets/fonts/`, alongside the
original SIL Open Font License. Previously used Cormorant Garamond assets are
retained but are no longer registered, used, or preloaded by the website.
Non-Latin translated text uses the browser's script-appropriate fallback fonts.
